# Decisions

One line per decision. An "Accepted" decision must be followed. The rules for writing and changing decisions are in `AGENTS.md`.

| No. | Decision | Status | In one sentence |
|---|---|---|---|
| [0001](0001-division-of-labor.md) | Division of work | Accepted | The main agent coordinates; one subagent writes code at a time; a different one reviews. |
| [0002](0002-records-and-doc-structure.md) | Records and document structure | Accepted | A short rule file, a status file rewritten each session, a task list, and a few decision records. |
| [0003](0003-learning-process.md) | Learning process | Superseded by 0006 | The owner takes part in each design choice, writes selected parts by hand, and self-tests at each milestone. |
| [0004](0004-language.md) | Language | Accepted | Repository files are in English; learning notes and research reports for the owner are in Chinese. |
| [0005](0005-branching-and-merging.md) | Branching and merging | Accepted | `main` holds approved work; each task gets a branch and reaches `main` through a pull request that the owner merges. |
| [0006](0006-learning-through-real-work.md) | Learning through real work | Accepted | The owner learns by making each design choice and reading each change; no quizzes; the overall design and key decisions come first. |
