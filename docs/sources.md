| The sign-in part of the official FastAPI full-stack template: `create_access_token` and `ALGORITHM` in `backend/app/core/security.py`; `reusable_oauth2` and `get_current_user` in `backend/app/api/deps.py`; `login_access_token` in `backend/app/api/routes/login.py`; `authenticate` and `DUMMY_HASH` in `backend/app/crud.py`; `Token` and `TokenPayload` in `backend/app/models.py`; `SECRET_KEY` and `ACCESS_TOKEN_EXPIRE_MINUTES` in `backend/app/core/config.py`. Changed on purpose: (1) every failure to read the token, including a user that is not found, answers 401 with the header `WWW-Authenticate: Bearer`, where the template answers 403 or 404, so that a frontend reads 401 as "sign in again"; (2) the dummy hash is made at start-up from a random password by the project's own hasher, not written into the code, so its cost settings always match the real hashes; (3) the secret key is random at each start unless the variable POC_TOKEN_SECRET_KEY gives one, where the template requires it, and a given key shorter than 32 characters is refused; (4) the token must hold both `exp` and `sub`, and `sub` must be a whole number; (5) the user name has the white space around it removed before the check, as when a user is created; (6) the template's `TokenPayload` model is not used: the token is read in one function that gives back the user id or nothing; (7) there is no prefix such as `/api/v1` before the addresses, and no check for an inactive user, because this project has no such field; (8) the functions that make and read a token take the secret key as an argument, where the template reads it from a settings object made when the module loads; (9) the settings are made once by `get_settings()` and shared, where the template makes one settings object when the module loads; (10) the lifetime of a token must be more than 0 and at most one year, where the template has no check; (11) the function that checks a name and a password does not replace an old hash after sign-in, where the template does; (12) the template signs in with an email address, and here it is a user name. | `backend/app/security.py`, `backend/app/users.py`, `backend/app/dependencies.py`, `backend/app/login.py`, `backend/app/config.py` | https://github.com/fastapi/full-stack-fastapi-template | commit `77e550a73bb49dd2967622c5ed11bf7a49603c93` (2026-11-16) | MIT (https://github.com/fastapi/full-stack-fastapi-template/blob/77e550a73bb49dd2967622c5ed11bf7a49603c93/LICENSE) | 2026-11-24 |
